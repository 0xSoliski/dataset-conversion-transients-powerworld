# Dataset License and Attribution

The shared PINN dataset collection is released under the Creative Commons
Attribution 4.0 International license (`CC BY 4.0`) for every dataset payload
whose rights are held by the project authors or whose upstream license permits
that sublicense.

Under CC BY 4.0, users may copy, redistribute, transform, and build upon the
licensed datasets for any purpose, provided that they:

1. credit the dataset creators and the cited upstream sources;
2. link to <https://creativecommons.org/licenses/by/4.0/>;
3. identify the dataset version DOI; and
4. indicate whether changes were made.

Suggested attribution:

> Falas et al., "PINN Power-System State-Estimation, FDIA, and Contingency
> Dataset Collection," Zenodo, version 0.2.0,
> <https://doi.org/10.5281/zenodo.21533592>, CC BY 4.0.

## Scope

CC BY 4.0 applies only to payloads explicitly marked `CC-BY-4.0` in the shared
release manifest. It does not relicense third-party source archives, simulator
case files, or upstream datasets.

Files whose redistribution rights have not been verified are excluded from the
public upload package. Their manifest entries retain source links, citations,
version identifiers, and checksums so an authorized user can obtain them from
the original provider.

The source code in the GitHub repositories remains under each repository's
software license and is not deposited in Zenodo.
